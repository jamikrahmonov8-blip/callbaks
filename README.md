# Callbacks и функции массивов (pop, push и др.)

## Что такое callback?

**Callback** — это функция, которую передают в другую функцию в качестве аргумента, чтобы та вызвала её позже.  
Проще говоря, колбэк — это способ сказать:  
*«Когда закончишь, сделай это».*

### Для чего нужны callback?

- Обработка событий (например, клик по кнопке).
- Асинхронные операции (например, загрузка данных с сервера).
- Повышение гибкости и переиспользуемости кода.

---

## Пример callback на JavaScript

```js
function greet(name, callback) {
  console.log("Привет, " + name + "!");
  callback();
}

function sayGoodbye() {
  console.log("Пока!");
}

greet("Алексей", sayGoodbye);
```
# Функции массивов в JavaScript (pop, push и др.)

В JavaScript массивы обладают множеством встроенных методов для работы с элементами.

---

### push()

Добавляет один или несколько элементов в конец массива и возвращает новую длину массива.

```js
let arr = [1, 2, 3];
arr.push(4); // arr теперь [1, 2, 3, 4]
```
pop-Удаляет последний элемент массива и возвращает его.
```cpp
let arr = [1, 2, 3];
let last = arr.pop(); // last = 3, arr теперь [1, 2]
```
map() Создает новый массив, вызывая callback для каждого элемента.
```cpp
let arr = [1, 2, 3];
let doubled = arr.map(item => item * 2); // [2, 4, 6]

```
filter()
Создает новый массив из элементов, которые удовлетворяют условию в callback.
```cpp
let arr = [1, 2, 3, 4];
let even = arr.filter(item => item % 2 === 0); // [2, 4]

```
reduce()
Выполняет функцию аккумуляции над элементами массива.
```cpp
let arr = [1, 2, 3, 4];
let sum = arr.reduce((acc, item) => acc + item, 0); // 10
